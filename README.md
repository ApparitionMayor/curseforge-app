# CurseForge App

### The largest modding platform and launcher

The CurseForge App gives you access to over 100,000 mods for Minecraft, World of Warcraft, The Sims 4, and dozens more games. Install, update, and manage mods with a few clicks through the world's biggest modding community.

<br>

---

## Features

| | |
|:---|:---|
| **100,000+ Mods** | The largest single repository of game modifications on the internet |
| **Multi-Game** | Supports Minecraft, WoW, Sims, Kerbal Space Program, and 50+ other games |
| **Auto Updates** | Mods update automatically when new versions are released by authors |
| **Modpack Creator** | Build and share custom modpacks with integrated packaging tools |
